# Gemma

### Google's open-source family of language models

Gemma is Google's family of lightweight, open language models built on the same research as Gemini. Designed for efficient on-device and cloud deployment, Gemma models excel at text generation, code, and reasoning tasks.

<br>

---

## Features

| | |
|:---|:---|
| **Multiple Sizes** | Available in 2B and 7B parameter variants for different hardware needs |
| **Instruction Tuned** | Fine-tuned versions follow complex instructions with high accuracy |
| **Responsible AI** | Built with Google's safety guidelines and responsible AI practices |
| **Broad Compatibility** | Runs on NVIDIA, AMD, Apple Silicon, and CPU via llama.cpp/Ollama |
